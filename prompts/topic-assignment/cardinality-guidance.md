# How many topics

Prefer fewer topics. An agent that belongs to one clear topic is placed better
than one spread across many. Two or three topics is a soft ceiling; past it,
membership stops meaning anything.

Do not silently grant broad membership. When a mission genuinely spans several
areas, that is usually a sign the agent is carrying too much, not that it should
join every topic. Assign the best-fitting few topics anyway, and say so in the
diagnostic: name that the mission appears to want more topics than one agent
should hold. The caller reads a high-cardinality diagnostic as its cue to raise a
split-this-agent Report to the coordinator; you assign, you do not split.

So on an overreaching mission: still return a real assignment to the few topics
that fit best, and record the overreach in the diagnostic rather than padding the
topic list.
